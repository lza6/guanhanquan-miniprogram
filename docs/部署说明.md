# 部署说明

## 前置

| 项 | 说明 |
|---|---|
| 小程序 AppID | 必须是已认证的小程序。测试号 `touristappid` 无法开通云开发，开发者工具会报「不存在此 AppID」 |
| 云开发环境 ID | 微信开发者工具 → 云开发 → 开通后得到，形如 `ghq-prod-1a2b3c` |
| 微信支付商户号 | 已认证主体可申请；云开发支付要求小程序与商户号完成绑定 |

## 一、小程序端

1. 填两个值：
   - `app/src/manifest.json` → `mp-weixin.appid`
   - `app/src/config.js` → `CLOUD_ENV`（留空则用开发者工具选定的默认环境）
2. 编译：

```bash
cd app
npm install
npm run build:mp-weixin
```

产物在 `app/dist/build/mp-weixin`，构建脚本会自动把 `cloudfunctions/` 拷进去并写入 `cloudfunctionRoot`。

3. 微信开发者工具导入该目录，点「云开发」开通环境。

## 二、云开发数据库

在云开发控制台创建下列集合（权限统一选「仅创建者可读写」，业务全部走云函数）：

```
users  jobs  applications  resumes  blacklist  favorites  wallet
notifications  reports  reviews  categories  banners  insurances
trainings  training_enrolls  user_insurances  orders  admins  configs  unlocks
```

建议索引：

| 集合 | 索引 |
|---|---|
| jobs | `status + isTop + createdAt`；`categoryId + status`；`ownerOpenid` |
| applications | `jobId`；`workerOpenid + jobId`；`employerOpenid` |
| blacklist | `bossPhoneHash + status` |
| favorites | `openid + jobId` |
| wallet | `openid + createdAt` |
| notifications | `openid + isRead` |
| users | `_openid`（唯一） |

`categories` 为空时会返回内置的 7 个工种（管工/焊工/普工/铆工/起重工/电工/技术员），可直接用，也可以自己插记录覆盖。

## 三、云函数

两个函数，都在 `cloudfunctions/` 下：

| 函数 | 作用 |
|---|---|
| `api` | 小程序与后台的唯一入口，内部按路径路由 |
| `pay-notify` | 微信支付结果回调 |

部署方式：开发者工具左侧 `cloudfunctions/api` 右键 →「上传并部署：云端安装依赖」。`pay-notify` 同样操作。

环境变量（云开发控制台 → 云函数 → api → 配置）：

| 变量 | 用途 |
|---|---|
| `ADMIN_INIT_PASSWORD` | 首次登录用的管理员初始密码，登录一次后建议改掉并删除该变量 |
| `ADMIN_SECRET` | 管理后台令牌签名密钥，随机 32 位字符串 |
| `CONTACT_KEY` | 联系方式加密密钥，泄露等于泄露全部手机号 |
| `PHONE_SALT` | 黑名单手机号哈希盐值，一旦设置不可更改，否则历史记录查不到 |
| `PAY_SUB_MCH_ID` | 微信支付子商户号 |

## 四、微信支付

1. 云开发控制台 → 云开发支付 → 绑定商户号。
2. 支付回调函数名填 `pay-notify`。
3. 小程序端调用 `/wallet/recharge` 下单，`pay-notify` 收到回调后落账，幂等由订单状态保证。

## 五、管理后台

```bash
cd admin
npm install
VITE_API_BASE="https://<你的环境ID>.service.tcloudbase.com/api" npm run build
```

- 云开发控制台 → 云函数 → `api` → 开启「HTTP 访问服务」，得到上面那个域名。
- 把 `admin/dist` 上传到云开发静态网站托管。
- 本地开发：`npm run dev`，Vite 中间件会用内存数据库直接跑同一套云函数代码，不依赖云环境；默认带演示数据，要关掉就设 `GHQ_DEV_SEED=0`。

## 六、上线前检查

- [ ] `ADMIN_INIT_PASSWORD` 已删除或改密
- [ ] `CONTACT_KEY`、`PHONE_SALT`、`ADMIN_SECRET` 都是随机值且已备份
- [ ] 小程序类目资质（招聘/求职需《人力资源服务许可证》）
- [ ] 黑名单申诉入口可用（被标记方可申诉）
- [ ] 支付回调在商户后台可查，金额一致
