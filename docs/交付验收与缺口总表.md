### 仍然属于“外部条件”而非代码缺口

- 微信支付真实扣款：需商户号绑定后，用 1 分钱真实验证。
- 真机 `getPhoneNumber` 绑手机：需已认证 AppID + 云环境。
- 云函数部署、集合/索引创建、环境变量配置：需云开发环境 ID。
- 招聘类目资质、人力资源服务许可证：需运营主体办理。

### 两项明确产品取舍

1. **地区筛选按市级匹配**：UI 是省/市/区三级选择器，后端只按“市”匹配 `workArea`；区县不参与过滤。
2. **短信验证码登录未接入**：登录采用微信一键登录 + `getPhoneNumber` 绑手机；短信服务商与模板未配置。

## 九、合规与上线前置

1. **类目资质**：招聘/求职类目需《人力资源服务许可证》或微信认可资质；个体工商户主体需向当地人社部门与微信确认。

3. **支付**：积分不可提现、不退款条款已写入用户协议；若做工资担保/托管属于另一套金融合规，当前未做。
4. **内容审核**：招工、简历、黑名单、举报均有人工审核入口。
5. **客服**：`open-type="contact"` 需在微信公众平台配置客服；未配置时按钮无会话。
6. **密钥**：`CONTACT_KEY`、`PHONE_SALT`、`ADMIN_SECRET` 生成随机值并离线备份；`PHONE_SALT` 设置后不可更改。
7. **数据备份**：云开发数据库配置备份。

## 附录 A 需求基线摘要（原 PDF 第一至第十章）

- **定位**：焊工、管工、铆工、起重工垂直招工找活平台；运营主体沈阳市苏家屯区管焊圈互联网服务网店（个体工商户）；信息发布 + 直接联系。
- **核心模块**：首页信息流、招工详情、发布招工、求职简历、黑老板查询、个人中心、管理后台。
- **核心流程**：发布 → 审核 → 展示 → 浏览 → 解锁联系方式 → 报名 → 录用；黑老板查询 → 提交 → 审核 → 展示/申诉撤销；签到/充值 → 解锁/置顶。
- **技术建议**：uni-app + Vue2、uView、腾讯地图、Vuex；后端 PHP/Node/Java + MySQL + Redis + COS + 短信 + 微信支付。当前实现为 uni-app 3 + Vue3 + 微信云开发（云函数 + 云数据库 + 云存储），功能等价；短信、腾讯地图 SDK、Redis、消息队列、定时任务未引入，相应能力用微信登录、`picker mode="region"`、懒过期替代。
- **成本参考**：基础版 10–16 周，4.5 万–8 万元；现成招聘系统二次开发 2 万–4 万元。
- **合规**：人力资源服务许可证、微信招聘类目资质、信息审核、隐私保护、投诉举报、资金安全。
- **差异化机会**：在线聊天、工资担保/托管、技能认证、考勤打卡、培训对接、多端适配。当前培训/保险/公告已做；在线聊天、工资托管、考勤未做，属于后续产品范围。
