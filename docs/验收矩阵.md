## 一、实测证据（打本地 API，参数完全照页面代码发送）

| 场景 | 发送 | 实际返回 | 结论 |
|---|---|---|---|
| 搜索页搜「管工」 | `?page=1&size=10&search=管工&sortBy=salary` | `total=2, pageSize=20` | 搜索未生效（全量返回），分页被忽略，排序无效 |
| 发布页提交 | jobPost.vue 的完整 `requestData` | `400 缺少必填项：categoryId` | **发布功能在真实页面里必然失败** |
| 绑定手机号 | `POST /auth/bind-phone` | `200 {phone}` | 后端正常，**前端 api 层没有 `bindPhone` 方法**，login.vue 调用会抛 TypeError |

## 二、契约错配（页面 ↔ 后端）

| 页面 | 发送字段 | 后端读取 | 后果 |
|---|---|---|---|
| index / jobSearch / employer-jobs-list | `size` | `pageSize` | 永远每页 20 条 |
| jobSearch | `search` | `keyword` | 搜索框不起作用 |
| jobSearch | `sortBy` / `sortOrder` | 无 | 排序按钮无反应 |
| jobSearch | `location` | `city` | 地区筛选无效 |
| jobPost | `categoryId: parseInt(...)` | 字符串 key（如 `guandao`） | `NaN`，必填校验直接拒绝 |
| jobPost | `location` / `requirements` / `paymentType` / `urgent` | `workArea` / `certificateReq` / `payType` / `isUrgent` | 即使通过校验，入库字段也是错的 |

## 十、UI 验收工具链（2026-11-10 晚）

### 已建立

| 工具 | 用途 |
|---|---|
| `scripts/wdt-mcp.cjs` | 直连微信开发者工具 MCP（stdio JSON-RPC，49 个工具），可列项目、读控制台、截模拟器、跑自动化 |
| `e2e/run.cjs` | miniprogram-automator 驱动：逐页截图 + 断言数据 + 收集 console 错误 |
| `e2e/shots/` | 截图输出目录 |

用法：

```bash
# 1. 打开项目并开启自动化端口
cli.bat auto --project <仓库根目录> --auto-port 9420

# 2. 本地 API（无云环境时）
node scripts/dev-api.cjs

# 3. 跑 E2E
cd e2e && node run.cjs
```

### 当前阻塞

`cli auto` 能起端口（9420 监听中），但连接时返回
`getClients timeout: client "s1|RENDERER_PROJECT" did not connect`——
说明 IDE 的项目渲染进程没有起来。同时：

- `cli open` 返回成功，但 MCP `simulator_screenshot` 报 `project window not found`
- `cli preview` 超过 180 秒未返回
- 桌面截图工具返回 `USER_CONTROL`（用户正在操作机器）

结论：**自动化链路本身已就绪，缺的是 IDE 项目窗口处于运行态**。等窗口正常打开后，`node e2e/run.cjs` 会输出 10 张页面截图与逐项断言，无需任何桌面点击。
