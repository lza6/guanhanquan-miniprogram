## 三、本轮复审发现并已修复的缺陷

| 级别 | 问题 | 位置 | 为什么测试没发现 |
|---|---|---|---|
| P0 | `/wallet/pay-notify` 对普通用户开放，任何人可构造请求把订单标记为已付并入账 | `router.js` | 测试只验证了合法路径，没测越权调用 |
| P1 | 关键词检索用了 Mongo 风格 `$or`，云数据库不支持 | `handlers/jobs.js`、`workers.js`、`admin.js` | 内存版 mock 支持 `$or`，造成假绿 |
| P1 | `todayKey()` 月日未补零，`new Date('2026-1-5T00:00:00+08:00')` 解析不可靠，签到可能失效 | `handlers/wallet.js` | 测试日期恰好是两位数月份 |
| P1 | HTTP 访问服务路径带前缀时会被重复拼接成 `/admin/api/admin/...`，后台线上必 404 | `lib.js parseHttpEvent` | 本地 dev 中间件直接传裸路径，绕过了这段 |

修复后回归：`node test/run.js` → **42 通过 0 失败**（新增关键词、薪资区间用例）。
